# SP2S 一代 vs 二代烟弹

| Field | Value |
|-------|-------|
| **Version** | 1.0.0 |
| **Last Updated** | 2026-07-08 |
| **Sources** | [podpickguide.com/sp2s-gen1-vs-gen2-pods](https://podpickguide.com/sp2s-gen1-vs-gen2-pods) |

| 维度 | 一代 | 二代 |
|------|------|------|
| **结构** | 较早产品线，部分弹匣形状不同 | 扁长型磁吸/卡扣，通用弹为主 |
| **相容主机** | 一代专用主机 | 二代专用主机 |
| **跨代混用** | ❌ 不可 | ❌ 不可 |
| **口味数量** | 较少 | 较多（32+ 款） |
| **系列完整度** | 基础口味 | 果凉、茶饮、重凉、季节限定较完整 |
| **选购建议** | 确认主机标示「一代」 | 确认主机标示「二代」 |

## 选购检查清单

1. 确认主机品牌与型号（SP2S Pro、通用杆等）
2. 确认要买「一代」还是「二代」弹匣
3. 同一口味不同代数风味接近，但不能混用弹仓
4. 批量购买前先买单颗或 3 入试口味
